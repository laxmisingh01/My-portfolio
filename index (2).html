Featured project, full-stack with AI

SERVD

AI-powered recipe generation platform

Tell SERVD what's in your pantry and it writes recipes around those ingredients using Google Gemini AI. Profiles, pantry inventory and saved recipes live in a full-stack Next.js app.

The problem
Working out what to cook from what you already have is slow, and unused ingredients go to waste. SERVD improves meal discovery and reduces food wastage.
Key features
  • AI-generated recipes from user-provided pantry ingredients
  • Secure authentication and protected routes with Clerk
  • Strapi CMS workflows for profiles, pantry inventory and saved recipes
  • Deployed on Vercel with API security and third-party integrations configured
  • Next.js
  • React
  • Strapi CMS
  • Clerk
  • PostgreSQL
  • Gemini AI
Live demo GitHub

AI, biometrics

SnapClass

AI-powered attendance system

An attendance system that identifies people by their face and their voice, with a Streamlit app on top of a Supabase SQL database.

The problem
Attendance has to be accurate and secure. SnapClass identifies people through facial recognition and voice biometrics and records attendance in real time.
Key features
  • Facial recognition and voice biometrics, supported by SVM-based identification
  • Secure authentication with role-based access
  • Streamlit application with Supabase SQL for real-time attendance and user management
  • Python
  • Streamlit
  • Supabase
  • SQL
  • Scikit-Learn
  • Dlib
  • Librosa
